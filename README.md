# Saturncraft

A single-player, browser-based voxel survival sandbox written from scratch in
JavaScript + WebGL ([three.js](https://threejs.org)). It reproduces the
observable mechanics of the classic block-survival genre's reference game
(version 1.21) — block behaviour, physics, survival, mobs, drops, spawn rules,
crafting progression — but on a moon with **three suns** and a **ringed gas
giant** hanging in the sky.

Every name, texture, model, sound and UI element is original and generated
procedurally at runtime: there are no image or audio files in the project.
Documented numbers (hardness, tool multipliers, drop chances, spawn weights,
light levels, damage, hunger values, movement speeds) come from the reference
game's public community wiki. In this document **"vanilla"** means that
reference game.

## Quick start

**Play online:** https://landerverpoest-code.github.io/saturncraft/ (deployed
by `.github/workflows/pages.yml` on every push to `main`).

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests (vitest)
npm run build      # production build in dist/
```

Requires a WebGL2 browser (any current Chrome, Edge, Firefox or Safari).
Click the canvas to capture the mouse. The world is saved to IndexedDB every
minute and on *Save & Quit*; *Continue World* on the title screen resumes it.

**World management** (title screen): the world list shows each world's screenshot (taken on every save), name, seed, play time, last played and size, with rename, copy, export, backups and delete (with confirmation). *Export* downloads one compressed `.saturnworld` file; *Import world* validates it (checksum, format version, size and chunk limits, nothing in it is ever executed) and adds it under a unique name. The last 3 snapshots of each world are kept automatically (about one per 15 minutes) and can be restored from the list; a world that fails its integrity check offers *Repair* (damaged chunks are dropped and regenerate from the seed, the original is kept as a backup) or a backup restore. A banner warns when browser storage is nearly full, and a failed autosave says so in game. *More world options* when creating a world: seed text, game mode, difficulty, cheats on/off, seasons (starting season, days per season), day/night cycle, hostile mobs, world events. (A flat world type is not offered: the terrain generator has no flat mode.) Saves carry a schema version and are migrated on load; `tests/fixtures/saves` holds one fixture per format.

Handy URL parameters for development: `?autostart=1&seed=123&rd=8`
(`&continue=1` to resume the save). `window.__game` exposes the running game
in the console.

## Multiplayer

Play with up to **8 friends** in one world, peer-to-peer over WebRTC — there is
no game server, so it works on the static GitHub Pages build. The free public
[PeerJS](https://peerjs.com) signalling server only introduces the browsers;
after that all traffic goes directly between them.

**Host:** start or continue a world, press **Esc** and choose **Open to Friends
(host)**. The pause menu then shows a short room code (e.g. `K7QX2M`) and a join
link (`…/?join=K7QX2M`) with a copy button. Your world keeps running while the
pause menu is open; the host's world is the one that is saved (including
everything guests build).

**Join:** on the title screen enter the code next to **Join a Friend** (or just
open the join link). Your name comes from the **Your name** field (remembered in
the browser, `Player-1234` by default). The world downloads, the terrain is
generated locally from the host's seed, and you appear next to the host.

Every player can do everything; the host's game decides what happens.

| | How |
|---|---|
| World | seed + every edited chunk on join (the save format's RLE chunks); then block edits both ways. The host validates guest edits (reach), applies them with their consequences (supports, fluids) and rebroadcasts every change in its world — fluids, fire, crops, explosions — to everyone. The host keeps the chunks around every guest loaded, so crops grow, leaves decay, sand falls and mobs spawn there too. |
| Players | position, look, held item, sneaking, crawling, swinging, sleeping, riding at 10 Hz; drawn with the third-person player model and a name tag |
| Mobs | simulated by the host around every player; they chase the nearest player. Guests see 10 Hz copies and their hits (melee, arrows) are applied by the host. Guests feed and breed animals, shear and dye fleecers, tame Howlers, Vixlings, Cragbucks, Hoppers, Bristlebacks and Frostbears (the guest becomes the owner: the pet follows, defends and sits for that player only) and trade with settlers (the host counts the uses; a guest who is a Village Champion pays the lower price). Leads and Name Tags work for guests too: the host leashes (the animal follows that guest), ties to and unties from fence posts and names the mob, and every player sees the name labels and the ropes to whoever holds them (a player or a fence knot); a guest who leaves lets their leads fall |
| Deep Hush & raids | the host's sensors hear guests too (footsteps and landings worked out from their positions, blocks they place and break from their edits, eating, doors, levers, chests and dropped items from a distance-checked message), every player has their own warning level, a shriek's Darkness reaches guests, and guests see a Hushkeeper rise out of / sink into the ground. Guests near a raided village see the raid bar (sent once a second) and become Village Champions if they are in the village when it is won |
| Armour stands | owned by the host; a guest's item leaves their hand when they click and the host's answer to that request hands back what came off the stand (or the item itself if refused), so a slow or lost answer can never duplicate it |
| Items, orbs, arrows, boats, falling blocks | shared entities owned by the host: block drops, death drops, thrown items (Q), arrows and boats of any player appear for everyone; picking up asks the host, which hands each item to exactly one player. Boats can be ridden by anyone (the rider steers) |
| Chests & furnaces | owned by the host: opening one on a guest shows the host's contents, every click is checked against the host's copy (if someone else took the stack first, the click is undone), furnaces smelt on the host, and several players can use the same chest at once. Dungeon loot is rolled once, by the host |
| PvP | on by default (**PvP: On/Off** in the host's pause menu); the victim's own game applies the damage with its armour; death drops become shared items, guests respawn at their own bed |
| Sleeping | the night is skipped once every player is in bed |
| Commands | `/time`, `/weather`, `/gamerule`, `/summon` and `/dimension` typed by a guest are run by the host for the whole world (**Guest commands: On/Off**, default On); player commands (`/give`, `/tp`, `/gamemode`…) act on the guest |
| Dimensions | the group travels together: when the host (or a guest, by stepping through a portal or with `/dimension`) goes to the Cinderdeep or the Hollow, everyone follows and arrives next to the host |
| Time & weather | from the host, once a second |
| Chat | `T`, messages go to everyone with the sender's name; join / leave notices |
| Guest inventories | kept in the host's save by player name, restored on rejoin |
| Player list | hold **Tab**: everyone with their team colour, game mode (Survival / Creative / Adventure / Spectator) and ping (measured by each guest, shown for all); `/list` prints the same |
| Private messages | `/msg <player> <text>` (also `/w`, `/tell`), `/r <text>` answers the last one; only the two of them see it |
| Teams | `/team create <name> [color]`, `/team join <name>`, `/team leave`, `/team list`, `/team color <color>`, `/team disband`, `/team ff <on\|off>`, `/tc <text>` for team chat. Members have coloured names (name tags, markers, chat, the Tab list). **Friendly fire is off by default**: team mates cannot hurt each other with melee, arrows or PvP until the team's owner (or an op) runs `/team ff on`. Teams are kept in the host's save |
| Ping beacons | press **B** (or `/ping`) to drop a beacon on the block you look at: a glowing column and diamond in the world, shown on every team mate's HUD (pinned to the screen edge with an arrow and the distance when off screen) for 20 s. One per player, once a second, up to 250 blocks away; without a team it goes to everybody |
| Emotes | press **V** for the wheel, or `/emote <wave\|point\|sit>`: the other players see the pose on your model (a seat lasts until you walk off); your own body shows it in the third-person views (F5) |
| Spectating | dead guests get a **Spectate a Friend** button on the death screen; creative players (and the host) use `/spectate [player]`. The camera follows the friend's position and view, the mouse wheel picks the next one, **Shift** (or `/spectate off`) lets go and returns to the previous game mode |
| Kick, ban, ops | host and ops: `/kick <player> [reason]`, `/ban <player> [reason]` (online or offline), `/pardon <player>`, `/banlist`; the host alone runs `/op`, `/deop`, `/oplist` (ops cannot remove the host or each other). The pause menu has a **Kick** button per guest. Ops, bans, teams and guest identities are saved with the world. Bans go by name *and* by a random token each browser keeps (`localStorage`), so a new name from the same browser stays banned; a different browser, or cleared site data, gets round it |
| Names and identity | each browser sends a random token with its join; the host remembers which token first used a name, so a second browser cannot take over an op's, a team mate's or a guest's name (it joins as `Name-2`) |
| Join code | the pause menu shows the room code and join link with **Copy Link** and **Copy Code** buttons; guests see (and can copy) the code too, to pass it on |

Compatibility: the social features add optional fields (`hello.tok`, `welcome.soc` / `.teams`) and new message
types that older builds ignore, so `PROTOCOL_VERSION` stays 2 and old and new builds still join each other (the new
commands tell a guest when the host is too old). Tests: `tests/social.test.js` (includes a loopback host and guest, the
transport behind `?net=local`).

Disconnects: a guest who leaves is removed for everyone. If a guest's link to the host drops (timeout, closed
connection) the screen says so and **reconnects by itself** after a few seconds (or at once with **Reconnect now**):
the page reloads and rejoins the same room, up to 5 times, and the guest comes back where they stood with their
own inventory, health and experience (their game keeps a copy from the moment the link went; the host's copy,
which also keeps their last position, is the fallback, and a guest who died is restored from the host's record
because their things lie on the ground). The host replaces the old half-dead link of the same guest at once. A kick,
a ban, a different game version, a full world or the host closing the world end at the title screen with the reason.
If the host quits, guests see a message and go back to the title screen.
Single-player is unchanged when no session is open (the networking code in
`src/net/` is only loaded when hosting or joining).

Limits:

* All players are always in the same dimension (no split parties across dimensions).
* Raids start only from the host's Dark Omen: a Captain killed by a guest lays the omen on the host.
* A lead a guest holds is saved like the host's: after a reload the animal is back on the host's lead.
* The Void Wyrm boss bar is only shown to the host; guests fight the same boss.
* The host's tab should stay open (background tabs keep simulating, throttled);
  everything depends on the host's machine and connection.

For development, `?net=local` swaps WebRTC for a `BroadcastChannel` loopback
between two tabs of the same browser, and `?peerhost=…&peerport=…&peerpath=…&peersecure=0`
selects a self-hosted PeerJS server.

## The world

* **Chunks** are 16×16 columns, 384 blocks tall (y = −64 … 319), sea level 63.
* **Block ids** are 16 bits: the original blocks use 1–255, item ids use 256–1023, and newer blocks start at 1024 (`EXT_BASE` in `src/world/blocks.js`, numbered in the order they are listed, so only ever append). Old saves with 8-bit chunks still load.
  Generation and initial lighting run in a pool of Web Workers; light is then
  stitched across chunk borders on the main thread.
* **Meshing** is face-culled per 16³ section (in workers), with vanilla-style
  smooth lighting and ambient occlusion, then merged into two draw calls per
  chunk (opaque + translucent). Player edits are re-meshed synchronously so
  there is no flicker. Textures live in a mip-mapped texture array.
* **Terrain**: continentalness / erosion / ridge noise splines for height,
  3-D density noise for overhangs, temperature and humidity for 11 biomes
  (ocean, frozen ocean, beach, plains, forest, birch forest, taiga, snowy
  plains, desert, stony peaks, snowy peaks), smooth grass/foliage tinting,
  bare rock on steep slopes.
* **Caves**: "cheese" caverns and "spaghetti" tunnels from interpolated 3-D
  noise; lava fills cave air below y = −55; deepstone below y = 0 with a
  dithered transition; bedrock floor.
* **Ores** use the vanilla per-chunk feature table (counts, uniform/triangle
  height distributions, vein sizes, air-exposure discard) — e.g. diamonds peak
  near y = −59, iron has its mountain band, beryl only in mountains.
* **Blocks** break with vanilla hardness, tool multipliers, harvest tiers,
  the ×5 penalties for mining in water or while airborne, and the 5-tick delay
  between breaks. While mining, ten crack stages spread over the block
  (multiplied into its texture, so they follow its lighting), chips fly off
  the hit face and the arm chops continuously. Sand and gravel fall; plants, torches and cacti pop off when
  unsupported. Water spreads 7 blocks every 5 ticks, lava 3 blocks every 30
  ticks, with downhill seeking, infinite sources and lava/water hardening
  (obsidian / cobblestone / stone).

## Physics

The player and every mob run the vanilla movement integration at 20 ticks per
second: acceleration → swept AABB collision (Y first, then the larger
horizontal axis) → gravity 0.08 and drag 0.98 → friction (block slipperiness ×
0.91 on ground, 0.91 in air). Rendering interpolates between ticks.

| Quantity | Value | Measured in tests |
|---|---|---|
| Walk / sprint / sneak speed | 0.1 attribute, ×1.3, ×0.3 | 4.317 / 5.612 / 1.295 m/s |
| Jump | 0.42 b/t initial velocity | apex 1.2522 blocks, 12 ticks airtime |
| Sprint-jump boost | +0.2 in facing direction | |
| Terminal velocity | | 3.92 b/t |
| Step-up height | 0.6 | |
| Player box / eye | 0.6 × 1.8, eye 1.62 (sneak 1.5 / 1.27, crawl 0.6 / 0.4) | |
| Crawl speed | ×0.3 (as sneaking), no sprint or jump | |
| Fall damage | ⌈distance − 3⌉ | 10-block fall = 7 |
| Water / lava | 0.02 accel, ×0.8 / ×0.5 drag, buoyant jumping | |

Survival: 20 health, 20 food, 5 initial saturation; exhaustion from sprinting,
jumping, swimming, attacking, mining and taking damage; regeneration every 80
ticks at ≥ 18 food or every 10 ticks with saturation at full food; starvation
down to half a heart (Normal difficulty). Drowning after 15 s of air (2 damage
per second), lava 4 damage + 15 s of fire, fire 1 damage per second, cactus
contact damage, the 10-tick invulnerability window with damage replacement,
knockback, the attack-cooldown damage curve and critical hits.

## Three suns

The sky has three suns, each defined by its own orbital period, starting phase,
rise azimuth, orbital tilt, declination offset, colour temperature, intensity
and apparent size (`src/sky/suns.js`):

| Sun | Period (ticks) | Phase | Rises at | Tilt | Colour | Intensity |
|---|---|---|---|---|---|---|
| **Hearth** | 24 000 | 0.02 | 90° (east) | 20° | 5600 K, yellow-white | 1.00 |
| **Pale Warden** | 37 200 | 0.60 | 62° | 38° | 11 000 K, blue-white | 0.55 |
| **Ember** | 15 400 | 0.33 | 128° | 52° | 2700 K, red-orange (large disc) | 0.45 |

* **Day** = at least one sun above the horizon; **twilight** = exactly one sun
  up; **night** = all three below. Because the periods are incommensurable the
  pattern never repeats exactly: nights last roughly 1–7 minutes and occupy
  ~15 % of the time.
* **Combined light**: each sun contributes `intensity × smoothstep(elevation)`;
  the combination `1 − Π(1 − fᵢ)` drives the 0…11 sky-darkening value, exactly
  where vanilla uses its single sun. Effective sky light = raw sky light −
  darkening, so a lone Ember or Pale Warden gives a dim (light 9–10) "twilight
  day" where surface monsters still cannot spawn, while a fully dark sky gives
  light 4 like a vanilla night.
* **Mobs use the combined light**: hostile spawning uses the vanilla light test
  with the combined darkening, undead burn only when the combined sunlight
  counts as "day" (darkening < 4) and the brightness at their head exceeds 0.5,
  spiders turn neutral in bright combined light, voidwalkers flee daylight.
* **Rendering**: each sun has its own disc, glare and horizon scattering; where
  suns appear together their glows add and the scene light colour is the
  intensity-weighted blend of the visible suns. Each sun owns one
  shadow-casting directional light (three shadow maps in total); shadow maps
  are refreshed round-robin (brightest sun every 3rd frame, the others every
  6th) and lights below the horizon are switched off.

## Ringed gas giant

The world is a tidally locked moon, so the gas giant hangs almost fixed in the
southern sky with a slow libration.

* Ray-traced sphere in the sky shader with a **banded, animated atmosphere**
  (fbm noise with latitude-dependent differential rotation, polar hoods and a
  drifting storm oval), **soft limb glow** and a **subtle aurora** on the polar
  night side.
* **Rings** are a real mesh (`RingGeometry`) with a procedural density shader
  — broad bands, fine ringlets, a division gap — where **each radius rotates at
  its own Keplerian speed** (ω ∝ r^−1.5), plus 6 000 orbiting ice particles that
  follow the same law. Rings are **translucent** (back-lit side dimmer),
  show **specular glints**, receive the **planet's shadow** and cast their own
  shadow onto the cloud tops; the planet occludes the far side of the rings.
* **Lighting follows the actual sun directions**, so the planet shows phases,
  can be lit by suns that are below your horizon, and fades into the daytime sky.

* **Seasons** (`src/world/seasons.js`; reference: the seasons of the usual survival mods). A calendar derived from the world time: four seasons of 8 in-game days (`/season length <days>`), with `/season` to see where the year is and `/season set <spring|summer|autumn|winter>` to jump to the first day of one; the date also shows under the sun widget (and in F3) and the world remembers its calendar offset, season length and the rule in the save. The Vixling's perk is **forager**: while it trots beside you (within 8 blocks, not sitting) it digs up a small gift every 5 to 10 minutes (sweet berries, feathers, rabbit hide, bones, apples, glow berries, raw rabbit) and tosses it at your feet; the Cragbuck's is **guard**: it charges hostile mobs that come within 10 blocks of you and rams them for 3 damage and a good shove. Owner, sit state and the gift timer are saved with the world; the host runs the pet, guests see it (tamed, sitting and baby flags in the mob snapshot) and tame, feed and command it with a right-click
* **More companions: Hoppers, Bristlebacks and Frostbears** (same code as the Vixling and Cragbuck, `src/mobs/companions.js`): offer a wild **Hopper** a Gilded Carrot, a wild **Bristleback** a Baked Potato or a wild **Frostbear** Raw Redfin (1 in 3 each time, not while a bear is angry at you; hearts rise and the animal sits down wearing a band — pink ribbon, yellow sash, blue harness). Their usual food (carrots and flowers, carrots / potatoes / beetroot, Raw Silverfin) still only heals and breeds them. Tame ones have more health (Hopper 8, Bristleback 14, Frostbear 40), follow, sit and stand on an empty-hand right-click from their owner only, fight what hurt the owner and fight back when hurt; the young of a tame pair are tame and keep the owner. Perks: Hoppers and Bristlebacks are **foragers** with their own gift tables every 5 to 10 minutes (Hopper: carrots, rabbit hide, wheat seeds, bone meal, clay, a gold nugget; Bristleback: potatoes, beetroot, mushrooms, apples, beetroot seeds), the Frostbear is a **guard** that mauls hostile mobs near you for 5 damage. A tame Frostbear no longer rallies the wild bears nearby. Owner, sit state and gift timer are saved with the chunk and the tamed / sitting / baby flags travel in the mob snapshot as before (the layout is unchanged)
* **Baby animals for more species** (`src/mobs/youngAnimals.js`; reference: baby bees, llamas, axolotls, dolphins and polar bears): **Buzzlings** (fed Sunpetal or Redbloom), **Packhorns** (Wheat or Hay Bale, also in a caravan), **Gillnewts** (Glimmerfin; the hatchling takes one parent's colour), **Dolphins** (Raw Silverfin or Redfin) and **Frostbears** (Raw Silverfin) now breed like the farm animals: two fed adults walk, fly or swim to each other and a half-size baby appears (the parents wait 5 minutes, 1–7 XP). A baby drops nothing, grows up in 20 minutes (feeding it speeds that up) and is saved with its chunk even for the ambient kinds (Dolphins, Gillnewts), which would otherwise despawn. Guests see babies through the existing baby flag of the mob snapshot
* **Baby hostile mobs** (`src/mobs/babies.js`): beyond Shambler-kin, 6 % of **Skitterers** hatch as spiderlings (half size, 35 % faster, half the health, a bite of 1, half the string and no eye, 3 XP), 4 % of **Fizzlers** are Fizzlets (half size, 40 % faster, half the health, half the blast radius, half the powder, 3 XP) and 5 % of **Cinder Brutes** are cubs (half size, 40 % faster, 12 health, a blow of 3, nothing to loot, 4 XP). None grow up, and guests see them at half size. **Rime Rattlers** now drop 0-1 Arrows of Slowness on a player kill (about half the kills; Plunder adds more) on top of their arrows and bones

## Other dimensions

### The Cinderdeep (fiery underworld)

* **Getting there:** build an obsidian frame (interior 2–21 wide, 3–21 tall, corners optional; the smallest is 4×5 outside) standing in the x or z plane and light its inside with flint and steel: it fills with violet **Rift** blocks. Stand in the Rift for 4 s (instantly in creative). One block in the Cinderdeep is 8 in the overworld; on arrival the nearest Rift within 16 blocks (Cinderdeep) / 128 blocks (overworld, loaded chunks) is used, otherwise a new 4×5 portal is built on a suitable floor near the target (or on an obsidian ledge carved into the rock). Portals you travel through are linked, so going back returns you to the portal you came from. Breaking the frame collapses the Rift.
* **World:** caverns between a bedrock floor (y 0–4) and ceiling (y 123–127), a lava sea up to y 31, soft red **Cinderstone**, **Mournsand** (slows you to 40 %) and gravel shores, **Glowshard** clusters hanging from the ceilings (light 15, drop Glowshard Dust; 4 dust = 1 block), **Emberquartz Ore** (Ember Quartz), ever-burning fires (fire on Cinderstone never goes out) and **Ember Bastions**: 97-block bridges of **Scorched Bricks** on pillars with a central hub holding an Ember Lord spawner and a loot chest (`/locate bastion`).
* **Rules:** red-orange haze instead of sky, no suns, no weather; water boils away when poured, ice does not melt into water; beds explode (power 5, with fire) when used — in the Hollow too.
* **Mobs:** **Ashwraith** (huge drifting shroud with trailing tendrils; spits exploding fireballs at players it sees within 64 blocks; drops blast powder), **Cinder Brute** (fire-immune melee brawler, 24 HP; gold ingots), **Ember Lord** (hovering, fire-immune, fires volleys of three small fireballs; drops **Ember Rods**, more of them around bastions). All have original box models.
* **Sub-biomes** (`src/world/dimensions/cinderBiomes.js`; none of the cave shapes, the lava sea, the bastions or the old ores change — two slow noises paint patches of about 100 blocks over the cavern floors, so the plain Cinderdeep is still the largest part and chunks away from the patches come out byte for byte as before):
  * **Glowcap Thicket** (about 15 % of the Cinderdeep): **Spore Loam** floors (a little slow) under pale **Glowcap Stalks** carrying domed, glowing **Glowcap Caps** (light 12; they drop 1–3 **Glowcap Spores**), a teal-green haze, spores drifting upwards, a soundscape of rustling and spore puffs. Home of the **Capwalker**.
  * **Slagfall Delta** (about 15 %): dark **Slagstone** floors with ridges of tall slag columns, **Slag Ore** (drops Slag Chunks; smelt either into a **Slagsteel Ingot**), a brown-grey haze with ash falling through it, hissing ash and popping lava. Cinder Brutes, Ember Lords and Ashwraiths hunt here.
  * **Dirgevale** (about 10 %, the soul-sand-like valley): cold blue-grey **Dirgestone** and Mournsand with **Wraithbone** spires and **Dirge Crystal Ore** (drops 1–2 Dirge Crystals, glows a little), a blue haze, rising wisps and far wails. Home of the **Dirge Wailer**.
  The fog colour and distance ease from one haze to the next as you walk, each sub-biome has its own looping noise bed and one-shot sounds (`src/audio/ambience.js`: `cinder_thicket`, `cinder_delta`, `cinder_vale`; new sounds *spore puff*, *ash hiss*, *dirge wail*, all captioned) and its own natural spawn table (`src/mobs/dimensionMobs.js`: `cinderThicket`, `cinderDelta`, `cinderVale`).
* **Capwalker** (neutral; `src/mobs/cinderMobs.js`): a glowing toadstool-folk that grazes among the stalks and ignores you until you hurt one; then it and its kin within 12 blocks chase you for 30 s and their bite poisons (5 s). 14 HP, drops 1–3 Glowcap Spores. **Dirge Wailer** (hostile): a pale shroud that drifts through the Dirgevale (the flight of the Ashwraith), keeps its distance within 32 blocks, rears up for a second and wails: whoever it can see within 7 blocks takes 4 damage and Slowness II for 4 s. 16 HP, drops bones, Wraith Tears and now and then a Dirge Crystal. Both have box models, faces and Field Guide pages made from the spawn tables like every other mob.
* **Cinderforges** (`src/world/dimensions/cinderForge.js`, built on `src/world/siteKit.js`; `/locate forge`): about every second 320×320 region holds an abandoned smithy, planned from the seed alone like the bastions and stamped chunk by chunk: a 25×25 courtyard of Scorched Bricks on pillars (walls 4 high, a Glowshard-crowned tower at each corner, a gate with a 26-block causeway), a lava pit with a low rim, furnaces along the back wall, anvils, stockpiles of Slag Ore, a Cinder Brute spawner and two loot chests (the dungeon and ruined-rift tables: all sixteen chest kinds are taken). It is a landmark kind for the Field Guide's Structures tab (the guide notes it when you walk within sight, as in the overworld), natural spawning inside it favours Cinder Brutes and Ember Lords, and the milestone *Cold Anvils* rewards finding one. Bastions are never overlapped.
* **Slagsteel, Dirgestep and Spore gear**: smelt Slag Chunks (or the ore) into **Slagsteel Ingots**; 3 ingots and 2 sticks make a **Slagsteel Pickaxe** (reference: a little better than iron: speed 7, 480 uses, mines diamond ore, mends with ingots). 4 **Dirge Crystals** make **Dirgestep Boots** (defence 3, 338 uses, mend with crystals): Mournsand, Spore Loam and other slow ground cost the wearer at most a tenth of their speed. 8 Glowcap Spores round an Ember Rod make 2 **Spore Lanterns** (light 15). Milestones *Light in the Dark* (walk into a Thicket), *Slag and Steel* and *Light on Mournsand*.

### The Hollow (void dimension)

* **Getting there:** craft an **Eye of the Void** (Void Pearl from Voidwalkers + Ember Powder; 1 Ember Rod = 2 powder). Right-click into the air to throw one: it flies ~12 blocks towards the nearest **Hollow Sanctum** (one per 640×640 region, 75 %; buried at y 10–31; `/locate sanctum`) and usually drops back (1 in 5 shatters). The sanctum is a stone-brick vault with a corridor, a Skitterer spawner, bookshelves, a loot chest and a ring of 12 **Hollow Frames** on a dais over lava (each frame has a 10 % chance to hold an eye already). Right-click every frame with an eye: the 3×3 centre turns into a starry **Hollow Gate**; fall in.
* **World:** a central island of pale **Hollowstone** (~100 blocks radius) floating in a black-violet starry void, outer islands beyond 800 blocks, ten obsidian pillars around the centre each crowned with a **Mending Crystal**, and the bedrock exit fountain in the middle. You arrive on a 5×5 obsidian platform at x 100. Many Voidwalkers.
* **The Void Wyrm:** a flying boss (200 HP, boss bar) that circles the pillars, swoops at the player (10 damage from its head, 5 from its body, plus a fling) and pulls up again; crystals within 48 blocks heal it (2 HP/s, shown as a beam) until they are shot or hit (they explode). Killing it opens the exit gate in the fountain, drops 12 000 XP and a **Wyrm Egg**, and unlocks the *Wyrmslayer* milestone. The exit gate takes you to your overworld spawn point (bed or world spawn).
* **The Far Gate** (reference: the void-island gateway): once the Wyrm is dead a small gate of two starry **Far Gate** blocks between bedrock opens on the main island's rim (80 blocks out, in a direction fixed by the seed; `/locate gate`). Walk into it to be thrown ~1000 blocks out to an outer island, where a matching gate leads back. The void between the main island and the outer islands is empty out to 800 blocks.
* **Outer islands** (one at most per 112×112 cell beyond 800 blocks, radius 8–27) carry **Hushvine** and, on the larger ones (60 % of islands of radius ≥ 15), **Hollow Cities** (`/locate city`).
* **Hollow Cities** (reference: the void-island cities; `src/world/dimensions/hollowCity.js`), planned from the seed and the island alone so every chunk stamps its share: a house of **Hollowbrick** (violet bricks; also **Hollowbrick Pillar**, **Slab** and **Stairs**) on a **Hollowstone Bricks** footing, a 12–19 block tower out of its roof with a ladder inside, a wide top room with two loot chests and **Wisp Rods** (light 14; reference: the light rods) on the roof; often (70 %) a railed bridge to a second tower with its own chest; sometimes (50 %) a **ship** moored at roof height (walkway from the roof) with a purple sail, a **Wyrm Head** trophy on the bow and two chests in the hold, one always holding a **Voidwing**. City chests roll 2–6 stacks of the reference table: diamonds (2–7), iron (4–8), gold (2–7), beryl, beetroot seeds, saddles, Drift Membranes, Sky Rockets and diamond/iron gear enchanted at level 20–39.
* **Gloomshells** (reference: shulkers; `src/mobs/gloomshell.js`) spawn inside cities (up to 6 per city). A violet box (30 HP) that peeks now and then and, closed, counts as 20 armour; with a player in sight within 16 blocks it opens and every 1–5.5 s fires a slow homing **Drift Spark** (4 damage + **Levitation** for 10 s). Below half health it may blink away. Drops a **Gloomshell Husk** (50 %).
* **Levitation** (status effect): instead of gravity the vertical speed eases towards 0.05 × level blocks/tick (≈ 0.9 blocks/s at level I); falling after it ends hurts as usual. `/effect give levitation 10`.
* **Gloomshell Box** (2 husks above and below a chest; reference: shulker box): a 27-slot container that keeps its contents when broken: the dropped box item carries them (`stack.contents`, kept in saves, on the network and when picked up), its tooltip lists what is inside, and placing it unpacks them. Boxes do not fit in boxes. Host-authoritative in multiplayer like chests (a guest placing a full box sends its contents to the host). A box and any dye make a box of that colour (16 **dyed Gloomshell Boxes**, re-dyeable, bone meal for white) that keeps its contents and name.
* **Voidwing** (reference: elytra): worn in the chest slot (two membrane wings on the player model). Press jump in mid-air to glide with the reference flight step: gravity is cancelled in proportion to cos²(pitch), descending turns height into speed, pulling up turns speed into height, the path swings towards the view and drag is 0.99/0.98/0.99 — a level glide covers about 8 blocks per block of height. Flying into a wall hurts (10 × speed lost − 3). It wears 1 use per second of flight (432 uses) and stops working at 1 use left; mend it with **Drift Membrane** (a quarter per membrane) or another Voidwing at the anvil.
* **Firework Stars and Star Rockets** (reference: firework stars and rockets; `src/world/fireworks.js`, `src/entities/skyRocket.js`): blast powder and 1–8 dyes (bone meal for white) press a **Firework Star**; one extra ingredient sets its shape — nothing: **small ball**, Fire Charge: **large ball**, Gold Nugget: **star-shaped**, Feather: **burst** (a ragged spray), Carved Pumpkin: **Fizzler face** — and a Diamond adds a **trail**, Glowshard Dust a **twinkle** (white crackle after the burst). Paper, 1–3 blast powder (the flight: 1–3) and up to 7 stars make 3 **Star Rockets** (a plain paper + 1 powder is still the Sky Rocket). The original per-colour star and rocket items are unchanged (a single dye is still a plain ball); anything richer travels in one extra stack field (`fw`), kept by saves, chests, drops and the network (the item message only gains a last element). A Star Rocket launched from a block bursts with every star in its own shape and colours (large balls and stars boom) and hurts the mobs within 5 blocks (5 + 2 per star; only the host or a single player deals it, a guest's rocket is for show; players are never hurt). Tooltips list the shape, colours and effects.
* **Fade colours, crossbow rockets and dispenser rockets** (`src/world/fireworks.js`, `src/entities/skyRocket.js`, `tests/fireworks_fade.test.js`): put an **Ink Sac** among a star's ingredients and the dyes *after* it (in the grid's reading order, up to 8) become its **fade colours**, the dyes before it its burst colours: the sparks start in the burst colours and turn to a fade colour over the last two thirds of their life, and a star with a trail fades its trail too (tooltip: "Fades to ..."; stored as an optional `f` list in the star's `fw`, which games without it ignore). A **Crossbow** drawn while **sneaking** takes a Star Rocket instead of an arrow (kept in the loaded crossbow's `fw`, free in creative) and fires it straight ahead at 1.6 blocks/tick; it bursts on the first block or mob it meets, or when its flight runs out, for 5 + 2 damage per star to every mob within 5 blocks (costs 3 durability). A **Dispenser** fires any rocket from its face: straight up it climbs like a lit rocket, sideways or down it flies straight and bursts on what it meets. **Players are never hurt by default**; `/gamerule fireworksHurtPlayers true` (saved with the world, default `false`) makes bursts hurt players too, except the one who shot or rode the rocket, and a player's rocket only hurts other players while PvP is on. Rocket boosts for a gliding Voidwing already exist (see Sky Rockets). No network message changes: the loaded rocket and the fade list ride in the existing `fw` stack field
* **Sky Rockets** (paper + blast powder → 3; reference: firework rockets; plain ones burst in one random colour and never hurt): used while gliding they push you towards 1.5 blocks/tick along the view for 20–31 ticks; used on a block they shoot up and burst into a ball of coloured sparks.
* **Hushvine** (reference: chorus plant; `src/world/dimensions/hushvine.js`): knotty stalks branching up to four levels from Hollowstone, with **Hushvine Flowers** at the tips; planted flowers grow, branch and wither on random ticks; breaking a stalk brings down what it holds. Stalks drop **Hushfruit** (0–1): always edible (4 hunger), it teleports you to a random standing spot within 8 blocks. Smelted it pops (**Popped Hushfruit**); 4 popped fruit → 4 Hollowbrick; an Ember Rod over a popped fruit → 4 Wisp Rods.
* **Wyrm Ribs** (`src/world/dimensions/wyrmRibs.js`; `/locate ribs`): the bleached ribcage of some long-dead Void Wyrm on about two in five city-less outer islands of radius 12 or more (never on the island the Far Gate leads to): a spine of **Wyrmbone** along the ground to a **Wyrm Head** skull, five pairs of arched ribs (the middle ones six blocks high) and a chest in the shelter of the spine that rolls the Hollow City loot table. Planned from the seed and the island alone through the island's plan, from its own random stream, so the cities and Hushvine of every island come out as before. Wyrmbone is a decorative block (4 bones make 2); the ribs are a landmark kind of the Field Guide and the milestone *What the Wyrm Left*.
* Milestones: *Tear in the World*, *Into the Cinderdeep*, *Ember Hunter*, *Eye in the Dark*, *The Hollow*, *Wyrmslayer*, *Beyond the Rim*, *The City at the Edge*, *Lighter than Air*, *Wings of the Void*, *Light in the Dark*, *Slag and Steel*, *Light on Mournsand*, *Cold Anvils*, *What the Wyrm Left*.

## Deliberate deviations

* **Original names and art** for every mob, item and block that is
  distinctive to the reference game (e.g. Deepstone, Cinnabar, Azurite, Beryl,
  Workbench, Blast Powder, Void Pearl). The zombie villager's spawn weight is
  merged into the Shambler (default 95 + 5, desert 19 + 1). Sodden Shamblers
  spawn in oceans (weight 5) and above all in rivers (weight 100, 1 attempt in 15; 1 in frozen rivers);
  swamp huts are tried at several spots of each 320-block region so they
  appear more often than the reference's sparse grid would in this world's small swamps.
* **Three suns instead of one sun + moon**: day/night is irregular. Sky
  darkening is derived from the combined light of the suns (see above) instead
  of the fixed 24 000-tick cycle; there are no moon phases (the gas giant
  shows phases instead) and no sleeping.
* **Hostile mobs can spawn under twilight skies only if the combined light is
  low enough**; with only the dim suns up, the surface stays at light 9–10,
  which is too bright for spawning but not "day" for burning — a state that has
  no vanilla equivalent.
* **Rare Shambler drop**: vanilla picks one of iron ingot / carrot / potato; only
  the ingot exists here, so it drops with 2.5 % × 1/3.
* **Dyes**: black dye comes from coal (the reference uses ink sacs) and brown dye is mixed from red + green (the reference uses cocoa beans), since neither source exists here; lambs take one parent's colour instead of blending.
* **Lighting**: sky light is stored per block and darkened in the shader by the
  combined sun light; the light curve blends vanilla's brightness formula with
  its default gamma. Fog is spherical. Leaves cast full shadows only where
  their texture is opaque. Sun shadows only come from terrain up to 140 blocks
  sunward of the player, so very long twilight shadows of distant hills end
  there.
* **Mob AI** is a simplified goal system (no goal priority selectors; a
  bounded A* of 250 nodes; panicking animals steer directly). Mobs do not seek
  shade from the suns, and there are no doors, wolves or cats to react to.
* **Water physics**: no bubble columns.
* **Explosions** do not set fire and do not knock items back.
* **The Hollow's late game**: there is a single Far Gate (the reference opens a new gateway per boss kill, up to 20) and it stands on the island's rim instead of floating at y 75; its far end is generated with the island rather than built on first use. Gloomshells spawn naturally inside a city's bounds (up to 6) instead of being placed with it, they sit on floors only, and Drift Sparks cannot be shot down. The ship's Voidwing lies in a chest rather than an item frame. Hollow Cities are a fixed house-tower-bridge-ship layout rather than the reference's random piece grammar.
* **Furnace** state is stored by block position rather than as a block entity;
  breaking a furnace drops its contents.
* **Render/entity distance**: entities render up to 64 blocks away and only
  cast shadows within 24 blocks; three shadow maps update round-robin.
* **Dropped items**: blocks drop as small turning 3-D cubes (two or three for stacks); other items drop as sprites rather than extruded 3-D models.
* **Step-up** (0.6 blocks) is implemented, but without slabs or stairs in the
  block set it rarely comes into play; full blocks always need a jump.
* **Saving** keeps modified chunks, the player, time, furnaces and animals;
  hostile mobs, dropped items and in-flight fluids are not saved.
* **Balance notes** (`node scripts/balance/report.mjs` prints the numbers, `tests/balance.test.js` keeps them in bounds). Found and fixed:
  a good name, the Lantern Festival and Village Champion cut the *goods a settler asks for its beryl* as well as the beryl price of its
  wares, and beryl prices bottom out at one, so "1 beryl -> 2 Hay Bales" sold back as 18 Wheat paid 1.3-1.5 beryl (and 4 Leather
  bought for 1 beryl sold for 1.33): cuts now only lower what you pay *in* beryl, a bad name still raises what is asked, and
  all cuts together take at most half off (Village Champion V + Hero + festival used to put a Diamond Chestplate at 7 beryl instead of 24);
  Plunder no longer multiplies a Marauder's beryl (0.5 a kill became 2 at Plunder III, a 4x currency faucet in raids); an enchantment
  loaded from a save, a guest or a mob's saved gear is clamped to its own top level (it was 10, so Keen X was possible). Checked and
  left alone: no buy -> craft -> sell loop remains in any reputation/festival/Champion/demand state across all twelve trades and the Peddler;
  no recipe chain multiplies resources and every craftable item is reachable (Cake needs an egg and milk, from a Cluckling and a Mooxen);
  chest kinds hold 1-26 beryl of goods on average (Hollow Cities and Ruined Portals richest, Pillager Outposts poorest), at most 1 Diamond and
  1.1 Gilded Apples per chest (Rimekeep barracks reuse the igloo table, so the Warden's keep always has two apples); fishing gives a Diamond
  1.1 % of casts (2.3 % at Luck III); the Rimekeep Warden (90 hp, diamond armour) takes 30-58 sword blows and the Hushkeeper 50-84, a
  fully drawn Strongdraw V arrow needs 18 and 34; four Bulwark IV pieces cap at 64 % off (diamond + Bulwark IV still takes 7 % of a hit);
  food values and the XP curve (1395 points to level 30) follow the reference numbers; a year of seasons grows crops at 0.87x the old
  rate (spring 1.35x, winter 0.35x), which is left as the price of having seasons.

## Performance

* Target: stable 60 fps at render distance 8 on a mid-range laptop GPU.
* Terrain at render distance 8 is ~1.9 M triangles in total. **Occlusion
  culling** (`src/world/visibility.js`) brings what is drawn down to ~0.3 M from
  the surface and a few thousand inside a sealed cave: every 16³ section records
  which of its faces connect through non-opaque blocks, and a flood fill from the
  camera (which never turns back against a direction it took) trims each
  chunk's draw range and bounding sphere to the sections it reached. A/B renders
  with and without culling are pixel-identical.
* Solid blocks, alpha-tested blocks (leaves, plants, glass, torches) and water
  are three separate meshes per chunk, so the solid pass has no `discard` and
  the GPU can reject hidden fragments before shading them.
* Generation (~15 ms/chunk) and meshing (~1.5 ms/section) run in a worker pool
  (`hardwareConcurrency − 1`, 2–6 workers); main-thread chunk work is budgeted to
  ~6 ms per frame; the simulation tick costs ~0.1–1 ms.
* Cave carvers (`src/world/carvers.js`) record each source chunk's tunnel paths once and keep them
  in a bounded LRU instead of replaying all 17×17 neighbours per chunk (carving ~6 ms → ~1 ms per
  chunk, output byte-identical). The mob spawner backs off to a rotating quarter of the chunks
  per tick while a sweep keeps finding nothing (e.g. the daylight surface pass) and caches its chunk
  list; the creative catalogue draws icons only for the rows in view (`src/ui/lazyIcons.js`).
* Third pass (after seasons, soundscapes, the new structures, companions and fireworks; `tests/perf_pass3.test.js`).
  Measured with Playwright (headless swiftshader, seed 42, render distance 4) and node: the new structure
  stamps cost under 0.01 ms per chunk each (sites are cached per region; generation stays ~16 ms/chunk, mostly
  ore veins and noise), a frame costs under 1 ms of JavaScript apart from the GL submit, the soundscape/acoustics
  rays ~0.05 ms once a second, and the heap stays flat over 12 000 simulated ticks. Fixed: random ticks skip
  sections without a tickable block (per-section counts kept by `setBlock`, 0.62 → 0.42 ms/tick), the entity list
  is compacted in place and item stacks test distance before comparing stacks, pressure plates no longer allocate
  an array per entity per tick (circuits 0.135 → 0.03 ms), `sameFw` skips serialising when neither stack has
  firework data, and the autosave encodes run lengths into typed arrays (1.6x) and keeps each chunk's packed
  copy until its blocks or light change. Tick cost with ~70 entities: 1.9 → 1.2 ms. The worker messages are
  transfers (generation ~0.4 MB per chunk, a mesh request 23 KB), nothing is copied.
* Shadows: three 1024² maps over a ±44-block area. The brightest sun's map is
  redrawn every 3rd frame and the others every 6th (the suns move ~0.3°/s;
  all three are redrawn right after a block edit). The shadow pass only draws
  sections that contain sky light and lie inside the light's frustum, which
  reaches 140 blocks sunward. The 17-tap shadow lookup is skipped for suns
  below the horizon, faces turned away from a sun, and surfaces without sky
  light (sunlight is scaled by sky light, so none of these change the image).
* The sky dome, rings and ice particles are drawn after the terrain with depth
  testing, so the gas-giant shader only runs on pixels where sky is visible.
* Turn shadows off in the pause menu on weak GPUs; lower the render distance
  for integrated graphics.
* Pixel ratio is capped at 1.25 (`pixelRatioCap` in the settings).
